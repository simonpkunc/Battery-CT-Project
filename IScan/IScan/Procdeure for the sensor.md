**Procedure to follow when using the sensor**

1) Open the software IScan.
2) Has the sensor been unused for a long time, tampered with (etc)?
    - if yes --> precondition it by loading and unloading it 3-5 times. This step is done in order to "wake up" the sensor.
    - if no --> proceed to step 3).
3) Make sure that there's load on the sensor.
4) Click *Tools* and *Adjust sensitivity*. Adjust the sensitivty so that the saturation is ok (high saturation = to much red & low saturation = to much blue), i.e. even colour distribution. Finish by clicking "OK".
5) Click *Tools* and then *Equilibration*.
6) A new window will pop up, click *Equlibrate-1*, set the time and click *Start*. Once done, finish the equlibration by clicking *OK*. This step is done to "zero" the sensor.
7) Once done and everything looks good, click *Tools* and *Calibration*.
8) A new window will pop up. Click *Ad*, specify the load for the calibration and press start.
9) Click on once done and in the window that pops up, click ok again.
